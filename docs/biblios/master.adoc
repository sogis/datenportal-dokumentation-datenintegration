= Anleitung für Datenlieferanten

Diese Anleitung begleitet Datenlieferanten der kantonalen Fachämter von der ersten Anmeldung bis zur laufenden Aktualisierung auf daten.so.ch. Sie erklärt den CSV-Lieferprozess mit einem begleitenden Datenblatt: welche Angaben und Dateien Sie vorbereiten, wer Sie unterstützt und wie die Veröffentlichung abläuft. Die letzten beiden Kapitel führen Schritt für Schritt durch die Erfassung der Metadaten und die Anlieferung der (Meta-)Daten an das Datenportal.
